# Experiment 006 — Cluster Structure

**Status:** Blocked — depends on Experiment 005.

**Purpose:** Organize cells into local circuits over a **fixed** topology
(e.g. 8 clusters x 16 cells). Determine whether local specialization plus
sparse global communication adds useful inductive bias. Dynamic/learned
topology is explicitly out of scope here (`docs/architecture_v0.md` Sec 3
and Sec 8).

**Prerequisite:** Experiment 005 (recurrent reuse validated on unclustered
cells).

**Hypotheses tested:** H3 (Circuit Hypothesis).
