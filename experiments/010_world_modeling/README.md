# Experiment 010 — Latent World Modeling

**Status:** Blocked — depends on Experiment 006 (a full, if small,
persistent-substrate model) and the synthetic-world generator
(`src/data/worlds/`, not yet implemented).

**Purpose:** Introduce procedural relational environments (Level 5 of the
benchmark ladder). Test whether the architecture develops stable world
representations: paraphrase invariance, intervention sensitivity,
counterfactual reasoning, relational composition, causal reasoning,
hidden-state inference, consistency — see `docs/benchmark_plan.md`
"World-representation tests" and `docs/hypotheses.md` "Operationalizing
understanding."

**Hypotheses tested:** H4 (World-State Hypothesis).
