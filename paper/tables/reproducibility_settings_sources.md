# Reproducibility-settings source trace

This appendix table was assembled from the frozen Paper-A harnesses and recorded JSON runs. No experiments were run, and no model or result code was changed. There is no separate YAML/JSON “config” file for these experiments: the protocol is defined by the harness/training modules and copied into each raw run record under `config`.

The frozen raw-record sets used here contain 220 Phase 1 records, 114 controlled-reliability/capacity records, and 36 real-reliability records (excluding history files). The processed aggregates were used for cross-checking dataset/model/seed coverage; raw records were authoritative whenever an aggregate had dropped a setting.

Model naming: tables display the model as **BVU**; its internal family id in the frozen records is `cellv0.3` (the identifiers and file names below are unchanged).

## Missing or non-applicable fields

- The frozen source does not provide a standalone config file. Values described as harness settings are recovered from the executed function defaults/arguments and checked against raw `config` fields.
- The processed aggregates omit some provenance fields. Width, effective batch, stopping cadence, and several config values therefore come from the matching raw record files rather than from the processed aggregate alone.
- The real-reliability runs do not define a `train_fraction`; they use the fixed APS official split and the chronological Air Quality split. The table labels this `fixed split` instead of inventing a fraction.
- HistGradientBoosting is a non-neural reference. Hidden width, trainable parameter count, optimizer, batch size, neural learning-rate candidates, neural step cap, and neural early-stopping patience are not applicable; its harness does not record them.
- A maximum epoch count is not recorded for the neural runs. The table reports the recorded maximum optimizer-step cap and does not convert it to epochs.
- The clean-benchmark size table (Table C1) is restricted to BVU and its `mlp_matched` comparison, the pair used by the clean benchmark figure (Fig S1). CellV0.1, CellV0.2 and the `mlp_state_count` arm are deliberately omitted because their clean results are not discussed in this paper. Their records remain in the frozen result files; they can be reported in a separate architecture-development appendix if one is added. Widths, parameter counts and batch sizes for the listed rows were re-checked against the raw `cellv0.3` and `mlp_matched` records.

## Clean-performance table (`clean_performance.tex`)

Generated by `paper/tables/make_clean_performance_table.py` (also writes `clean_performance_data.csv`, one row per dataset x train fraction, so every printed number can be re-derived without opening the PDF). No experiments were run and no result file was modified.

- **Sources:** `experiments/paper_a/results/processed/phase1_cellv03_runs.json` (BVU, 42 rows) and the `family == "mlp_matched"` rows of `phase1_runs_small.json`, `phase1_runs_mid.json`, `phase1_runs_mnist_0.25.json`, `phase1_runs_mnist_1.0.json`, `phase1_runs_fashion_mnist_0.25.json`, `phase1_runs_fashion_mnist_1.0.json`. Processed exports only, never raw or history files.
- **Values:** processed `headline_value` (test accuracy for classification, test R^2 for regression), mean and sample SD (ddof = 1) over seeds 0, 1, 2. Delta is the per-seed paired difference (BVU minus matched MLP), then mean and SD across seeds, the same convention as Fig S1.
- **Integrity checks in the script:** unique (dataset, train_fraction, family, seed) keys across the combined MLP sources, exactly three BVU seeds per cell, and a single headline metric per cell. The 100%-fraction deltas were checked against `paper/figures/supplementary/figS1_clean_benchmarks_data.csv` and match exactly.
- **Not applicable:** no significance test is reported (n = 3 seeds).
