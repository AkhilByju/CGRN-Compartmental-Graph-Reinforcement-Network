# Provenance: `aps_strata_counts.tex` (`tab:aps_strata_counts`)

The counts come from the official 16,000-example APS Failure at Scania Trucks test set, the file `aps_failure_test_set.csv` from the UCI archive zip (`aps+failure+at+scania+trucks.zip`, dataset 421). It was read from the local cache `~/.cache/cgrn_data/aps_failure_test_set.csv` (SHA-256 `2cdf6f7661c7b4c63333c93cdec36a3a82350176b604a2312cf82799fb2712f3`) through `_aps_frames()` in `experiments/paper_a/real_reliability/datasets.py`. This is the same frozen Phase-3 Part B test split used for Figure 3: the official test set is never resplit, and the split does not depend on the seed. Each example is assigned to a bin by its fraction of missing (`na`) values among the 170 features, using `MISSINGNESS_BINS` and `missingness_bin_index()` from that file, the same functions `evaluate.py` uses for the Figure 3 strata: `0`, `(0, 0.10]`, `(0.10, 0.25]`, `(0.25, 0.50]`, `>0.50`, with upper-inclusive edges. Positives are `class == "pos"`. Bin membership is identical across seeds 0, 1 and 2. For each seed, `prepare_dataset("aps", seed)` yields the same per-example bin index (identical SHA-256 `c00eec0e…cc72`) and the same test labels as the raw file, and an independent exact-integer binning of the per-example missing-feature count (thresholds 0, 17, 42, 85 of 170) agrees with it. The counts also match the `n` and `n_pos` stored in `evaluation.by_stratum` of all 15 frozen APS run records that store strata (5 neural families × 3 seeds) in `experiments/paper_a/real_reliability/results/processed/real_reliability_runs.json`. The 3 `hist_gradient_boosting` records store no strata and were not checked. Nothing was trained or evaluated, and no run record or model was modified. The table is regenerated by `python paper/tables/make_aps_strata_counts.py`, which fails without writing if any of these checks disagree.
